# Role-based Reading Guide (中文 + English)

导航 / Navigation: [返回项目首页](../../README.md) | [文档首页](../README.md) | [代码与 API 对齐](../reference/code-api-map.zh-en.md)

## 目的 / Purpose

中文：
这份指南按团队角色提供最短阅读路径，帮助新成员在最短时间内完成上手并进入有效协作。所有角色遇到“文档和代码不一致”时，以 [Code and API Map](../reference/code-api-map.zh-en.md) 与当前代码为准。

English:
This guide provides shortest reading paths by role so new team members can onboard fast and collaborate effectively. When docs and code disagree, use [Code and API Map](../reference/code-api-map.zh-en.md) and current code as the source of truth.

## 角色入口 / Role Entry

1. 开发者 / Developer
- 阅读: [developer-playbook.zh-en.md](developer-playbook.zh-en.md)
- 关注: API、Runtime、ReAct/code-mode、Provider Connection、Worker、数据模型、前端联调

2. 测试工程师 / QA
- 阅读: [qa-playbook.zh-en.md](qa-playbook.zh-en.md)
- 关注: E2E 场景、权限边界、Provider/MCP 故障注入、Run Timeline、验收清单

3. 运维工程师 / Ops
- 阅读: [ops-playbook.zh-en.md](ops-playbook.zh-en.md)
- 关注: 部署、迁移、密钥、Worker、监控、发布、回滚

4. 产品经理 / PM
- 阅读: [pm-playbook.zh-en.md](pm-playbook.zh-en.md)
- 关注: 功能边界、未实现能力、可观测指标、里程碑与验收
