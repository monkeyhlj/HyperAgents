# 设计方案

**主题**：MAISON NOIR — 一座虚构的勃艮第酒庄，专售陈年窖藏。受众为收藏家与品鉴者，页面任务是建立"值得托付时间"的信任感。

**色彩**：墨黑 `#0A0807` · 炭黑 `#161210` · 酒红 `#3A0E12` · 琥珀金 `#C9A24B` · 羊皮纸 `#E8DCC4` · 烟灰 `#8A7E6E`

**字体**：Cormorant Garamond（展示衬线，克制使用）· Inter（正文）· JetBrains Mono（数据/标签）

**签名装置**：酒窖拱门 — hero 中以 CSS 弧线 + 径向光晕构成的"拱顶聚光"构图，瓶身剪影立于拱心，呼应酒庄地下陈酿空间。

**布局**：全屏 hero 拱门聚光 → 三瓶藏品横向陈列（带年份/产区/风味数据）→ 双栏品牌起源（左图右文，引文居中）→ 四步品鉴仪式时间线 → 深色 CTA + 多栏 footer。
